## Vision

### 10x Check
aardbin 的差异化不是 pastebin 而是「个人多设备同步 Bin」：竞品（PrivateBin / MicroBin / Wastebin / Snip / Sipp）面向公开分享，aardbin 面向自己跨设备私用（SSE 实时同步 + 附件 + AES-256-GCM 静态加密 + HTMX 极简）。

### 12 个月可度量检查点
- awesome-selfhosted pastebins 分类收录（投递 PR 被合并）
- GitHub stars 与 issue 数量 > 0（有真实外部用户信号）
- GHCR 镜像 pull 数 > 0；至少 1 个外部部署案例
- 不设硬性数字目标，以上为「是否有人真的在用」的可观测信号

## 已定实现决策（0E + 张力裁决）

- **文档结构（T-A 采纳分层）**：README.md（双语、面向用户、单一上手文档）+ docs/SPEC.md（开发面设计档案，原 PRD 迁移、保留中文）；「未来迭代」章节由 **SPEC 承接**，README 只放一行链接指向 TODOS.md/SPEC；TODOS.md 为延期项唯一权威，交叉引用对象统一为 SPEC
- **版本号**：首发 **v1.0.0**；**1.1.0 从未公开，rebase 后旧号废弃（不视为回退）**；职责拆分：基线 B 只改文档中的版本字样，T14 负责 Cargo.toml / tag / compose / 镜像迁移；tag `v1.0.0`；镜像 `ghcr.io/aardpro/aardbin:1.0.0` + `latest`；自身在役实例同步迁移到 GHCR 镜像（dogfooding）
- **i18n（T-E 混合方案）**：模板双目录 + t() 翻译表覆盖服务端字符串与 toast + lang 选择器（自动检测+记住）；**Untitled 数据路径：回退链留在服务端（render.rs），列表项额外携带 data-first-line 属性，前端仅对空标题做显示替换——不改变存储格式、不冻结语言**
- **发布平台**：musl 静态二进制（x86_64/aarch64-unknown-linux-musl，rusqlite bundled）+ buildx 双架构 GHCR 镜像；**CI 交叉编译工具选 cross（或 zigbuild），在 T5 内落地**
- **CLI 鉴权（T-B 维持 Bearer + 限流）**：Bearer ACCESS_KEY；**限流桶语义：错 key 计入登录同一 IP 桶、429 响应带 Retry-After、CLI 线性退避；同 IP 连带锁死浏览器登录为已知可接受行为（单用户场景）**；Origin 校验仅浏览器端点；CLI 为 workspace 子 crate
- **JSON API 端点**：`POST /api/records`（multipart 复用现有上传）、`GET /api/records`（**分页参数 `?page=N&page_size=M`，默认复用 PAGE_SIZE**）、`GET /api/records/:id`、`DELETE /api/records/:id`、`GET /api/attachments/:id`；错误统一 `{"error":"..."}` + 状态码
- **发布节奏（T-C 维持全量）**：全量完成后发布 v1.0.0；例外条款：E3 延期则降级 v1.1 不阻塞首发
- **E1（T-D）**：仅 cargo-deny，不用 cargo-audit
- **无争议修复包（T-F 全采纳）**：①版本号对齐+自身实例迁移；②CSS 构建产物入库；③备份文档补「.env 与 data/ 一起备份，丢 key 即丢全部文本」；④routes 关键路径单测 + smoke SSE 计时稳健化
- **favicon**：移入基线（30 分钟；已从 TODOS.md 移除该项）
